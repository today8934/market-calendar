# 마켓 캘린더 · 매일 자동 갱신

한국과 미국의 금리 결정·경제지표·기업 실적·증시 휴장 및 일부 세계 중앙은행 일정을 한국시각으로 확인하는 GitHub Pages 캘린더입니다.

https://today8934.github.io/market-calendar/

- 주간/월간/목록 보기, 시장·분류 필터, 검색, 일정 상세와 원문 출처
- 관심종목 추가·삭제, 브라우저 저장, 관심종목 필터
- 정확한 발표 시각은 한국시간. 미국 장후 실적은 다음 한국 날짜의 새벽으로 표시하며 정확한 시각을 임의로 넣지 않습니다. 장 구분도 미정인 일정과 휴장은 현지 날짜입니다.
- 확인·예상·취소 구분, 개별 일정 ICS 다운로드

GitHub Actions가 매일 **오전 7시 KST**에 공개 데이터를 수집하고 같은 작업에서 Pages를 배포합니다. PC나 Codex 앱을 켜둘 필요가 없습니다. GitHub 예약 실행은 혼잡 시 지연될 수 있습니다. 공개 저장소의 예약 작업은 장기간 저장소 활동이 없으면 GitHub 정책에 따라 중지될 수 있으므로 화면의 최근 실행 시각을 확인하세요.

자동 수집 범위:

- 미국 연준 FOMC 공식 연간·월간 일정, BEA GDP·PCE·무역수지, BLS iCalendar.
- 한국은행 통계공표 일정, 한국거래소 KIND에서 제목에 실적 발표 또는 Earnings가 명시된 IR 행사. NDR은 제외합니다.
- Nasdaq 향후 30일 실적 캘린더: 시가총액 100억 달러 이상 또는 기존 기업 사전에 등록된 미국 기업. Nasdaq의 일정은 추정이 포함되므로 **예상·재확인 필요**로 표시합니다.
- 삼성전자 공식 IR 일정. 다른 개별 기업의 공식 콘퍼런스콜과 세계 중앙은행 일부·휴장은 확인한 자료를 별도로 반영하며 매일 자동 확인되지 않을 수 있습니다.

관심종목은 브라우저에 저장되며 기기 간 자동 동기화하거나 공개 저장소로 전송하지 않습니다. **업데이트 요청**을 복사해 Codex에 보내면 추가 종목의 수동 확인을 요청할 수 있습니다.

수집 실패 시 기존 이벤트를 삭제하거나 확인 시각을 새로 찍지 않습니다. 화면의 **수집 상태 보기**에서 실패 출처와 실행 시각을 보여줍니다. 48시간 이상 실행 기록이 오래되면 지연을 표시합니다. 출처에서 사라진 항목을 자동으로 취소하지 않으며 취소는 명시적 확인 후 반영합니다. 전체 상장사·모든 금융 이벤트의 완전한 목록은 아닙니다.

`events.json`이 원본 데이터이며 같은 데이터가 `index.html`에 삽입되어 있습니다. 두 파일을 함께 갱신합니다. 원본은 `main`이며 Pages는 `.github/workflows/daily-calendar.yml`에서 배포합니다. 방문 중에도 15분 간격으로 새 데이터를 확인합니다.

개발 확인: `python -m pip install -r requirements.txt`, `python -m unittest test_calendar.py`, `python update_calendar.py --validate`. 수집 실행: `python update_calendar.py`. 원문 접근 차단이나 형식 변경은 출처별 실패로 기록합니다. 페이지 내용은 스크립트로 실행하지 않습니다. API 키·유료 모델·별도 서버 없이 동작합니다.

데이터는 schemaVersion 1을 유지하고 market에 EU/JP/CA/NZ/AU/CN을 추가했습니다. `session`은 미국 실적의 before-open/after-close를 표현하며 `startsAt`을 대체하는 정확한 시각이 아닙니다. `automation`은 실행 결과, `history`는 날짜·시각·상태 변경 이력입니다. 기존 수동 갱신 스킬보다 이 저장소의 `validate`를 사용해야 확장된 시장을 검증할 수 있습니다.
