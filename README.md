# 마켓 캘린더

한국과 미국의 금리 결정·경제지표·기업 실적·증시 휴장 일정을 확인하는 개인용 GitHub Pages 캘린더입니다.

https://today8934.github.io/market-calendar/

- 월간/목록 보기, 시장·분류 필터, 검색, 일정 상세와 원문 출처
- 관심종목 추가·삭제, 브라우저 저장, 관심종목 필터
- 정확한 발표 시각은 한국시간, 휴장과 시각 미정 일정은 현지 날짜
- 확인·예상·취소 구분, 개별 일정 ICS 다운로드

관심종목은 브라우저에 저장되며 기기 간 자동 동기화하지 않습니다. 페이지의 **업데이트 요청**을 복사해 Codex에 보내면 `$market-calendar-update` 스킬로 최신 일정을 조사하고 배포할 수 있습니다. 페이지 버튼 자체가 스킬을 실행하거나 예약하지는 않습니다.

`events.json`이 원본 데이터이며 같은 데이터가 단일 `index.html`에 삽입되어 있습니다. 두 파일을 함께 갱신합니다. GitHub Pages 원본은 `main` 브랜치의 루트입니다. 모든 수집 일정은 원문 링크와 확인 시각을 가집니다. 보조 출처 기반 일정은 재확인 대상으로 구분합니다.
